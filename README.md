# Taxora posters

Posters for Taxora (Mithapur, Patna) Facebook/Instagram posts.

- Add `posters/<slug>.json` with `{"slug": "...", "tag": "GST · ITR · TDS", "body": "<poster body html>"}`.
- GitHub Actions renders `out/<slug>.jpg` (1080x1350) automatically.
- Public image URL: `https://raw.githubusercontent.com/taxorapatna/taxora-posters/main/out/<slug>.jpg`
